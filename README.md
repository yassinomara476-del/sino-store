نسخة Prototype قابلة للفتح مباشرة من index.html.

الموجود:
- عربي / English وRTL/LTR
- 51 variant من ملف الأسعار
- أسعار 7% / 8% / 9% / 10%
- سلة مشتريات وWhatsApp checkout على 01002633244
- Bundles مبدئية
- Admin تجريبي
- EGP
- Logo الخاص بـSINO-STORE

قبل الإنتاج:
1. نقل المنتجات إلى PostgreSQL/Supabase.
2. Authentication حقيقي للـAdmin.
3. ربط بوابة دفع مناسبة لمصر.
4. حفظ الأسرار في environment variables.
5. ربط مزود API عند توفره.
6. إعداد domain + HTTPS + production hosting.
7. إضافة الشروط وسياسة الخصوصية والتحقق من حقوق إعادة بيع كل خدمة.
